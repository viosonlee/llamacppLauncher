# KVMem 与内置引擎维护变更规格

版本：2026-11-07。基线：`c3e3644`。状态：已实现并通过验收；本文件不代表上游支持所有模型。

关联需求：[REQ-124～126](REQUIREMENTS.md#L255-L276)。实现与测量分别见 [KVMem 集成](KVMEM-INTEGRATION.md)、[更新维护指南](ENGINE-UPDATE-GUIDE.md)、[测试用例矩阵](KVMEM-TEST-CASES.md)。

## 1. 变更目的与范围

解决“UI 能生成参数，但本机原版引擎没有分页内核”的断点；为 RTX3060 Laptop 6GB 部署真实 sm86 KVMem，并完善所有内置引擎及必要运行库的统一更新、有限版本保留。

| 项目 | 变更前 | 变更后 |
|---|---|---|
| 后端 | 原版 llama.cpp / PolyStrata 上显示 KVMem 开关 | 注册独立 `kvmem`，保留两种原版后端 |
| 启用协议 | 裸 `--kvmem`；仅假参数断言 | 正数 `--kvmem-budget` 激活真实 PolyStrata 内核；补齐解码/历史契约 |
| 参数可见性 | 不具备能力的后端也显示分页参数 | 仅 KVMem 后端显示；依赖参数动态折叠 |
| 更新 | llama.cpp 版本未知即重下载；运行库可能混拷 | 真实版本检查，同发布/driver 兼容运行库；已最新不下载 |
| 安装 | 可能就地覆盖引擎/全局环境 | 独立版本目录，验证后原子提交安装路径 |
| 旧版 | 无统一上限 | 受管当前版 + 最近旧版；运行、手工和用户数据优先保护 |
| 配置 | 未知顶层字段写回时丢失 | 保留扩展元数据，窄事务避免覆盖模型参数/运行身份 |
| 失联恢复 | TCP 表漏报即拒绝扫描 | 限频执行完整身份扫描，不以表快照为唯一门槛 |

## 2. 界面与行为规格

1. 引擎下拉新增 **KVMem (PolyStrata · 分层 KV)**，默认后端仍为 llama.cpp；不擅自切换用户当前选项。
2. 顶部新增全局 **一键更新**，覆盖 `llamacpp`、`polystrata`、`kvmem`；再次点击取消后续工作，日志逐项报告结果。
3. 更新期间禁止参数/模型切换和新启动；关闭窗口先取消并等待结束，不能把更新前路径快照保存回配置。
4. 当前后端的 **配置环境** 同样走共享服务，显示真实失败，完成后重载安装路径。
5. KVMem 逻辑上下文默认65536、B8192、R512、Host1024 MiB、SSD0、保留历史2、预填充128、搬运区128 MiB、显存预留512 MiB、KV=q8_0；关闭不传分页参数。
6. KVMem 默认监听127.0.0.1:8080，不继承旧 Strata 的8091或外网监听值；显式用户地址/端口仍保留。
7. KVMem 的“打开页面”展示实际 `/props` 能力；本轮不启动上游统一聊天控制台，不承诺内置聊天页。

## 3. 原生协议与限制

- 当前仅支持 `qwen35moe` GGUF、单 NVIDIA GPU、fp16/q8_0、普通解码；NInfer、MTP、多 GPU 不在本轮范围。
- B/R须32对齐，B+R≤context，预填充≤R；SSD配额>0必须有目录。生效的非法组合报错，不静默调整。
- 自动设置 window1/no-draft/lookup0、清零旧会话缓存并开启history-reuse。保留历史数不是并行生成数，R不是总回复上限。
- 服务用完整包的匹配源码和Python，native环境通过runconfig `env/lib_dirs`传入；分词表由同GGUF导出并校验五件套，不为纯导出安装打包依赖。
- 就绪必须模型已加载、路径一致、实际预算/块大小/历史复用匹配，不只检查HTTP200。
- KVMem是块稀疏注意力，限制活跃KV但不消除权重、工作区、RAM或SSD不足；不保证所有输入质量、256K或百万上下文。

## 4. 更新、配置与回退

- GUI与CLI `--update --all`共用C#入口；单项失败继续报告其它项，用户取消终止后续；不停止真实服务。
- llama.cpp按真实build和driver上限选同release binary+cudart；PolyStrata按真实BUILD、同tag源码与exact NVIDIA pins准备新私有运行环境；KVMem更新完整架构专用包。
- SHA校验、安全解压、最终目录native/import验证后提交路径；失败或提交前取消不得切换安装。
- 安装路径比较交换保护并发编辑；仅同步仍引用相同旧公共安装路径的预设，不修改模型调优或独立手工路径。未知配置元数据保留。
- ownership与下载receipt限制删除范围；受管当前版+最近旧版。llama.cpp不同CUDA minor属于同一保留组，KVMem不同sm架构分组。
- 运行身份、手工恢复路径、模型/配置/用户日志优先保护。随包日志只有显式原始SHA/长度记录且未修改才可随旧包删除。
- 清理异常只报告，不回滚成功安装。未认领目录不自动删除；回退通过选择保留版本的匹配完整包路径完成。

验收基线为构建0警告0错误、108项自动回归全通过、65条需求门禁通过；真实32K/64K输入、SSD读写与历史复用已实测，详见测试矩阵。后续文档整理不自动重复GPU长文扫测。
